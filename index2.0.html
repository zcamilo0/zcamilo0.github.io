Documentación de la Estación

¿Qué mide la estación?

La estación meteorológica de Quibdó, Chocó, registra tres variables fundamentales del clima tropical húmedo del Pacífico colombiano:

  • Temperatura (°C): Valor de la temperatura ambiente medida.
  • Humedad (%): Porcentaje de humedad relativa en el aire.
  • Sensación Térmica (°C): Valor percibido que combina temperatura y humedad.

Fórmula del Punto de Rocío

Se utiliza una aproximación simplificada:

Punto de Rocío = T − ((100 − H) / 5)

Donde T es la temperatura en °C y H la humedad relativa en porcentaje. El resultado se redondea a 1 decimal.

Esquema del Registro

Cada muestra registrada contiene las siguientes claves en el esquema JSON:

temperatura, humedad, sensacion

Además, se almacenan la hora local de Bogotá (zona horaria de Colombia) para cada registro.

Acerca del Promedio

El promedio de las últimas 5 muestras se calcula al completar 5 registros. Una vez se alcanza este umbral, el búfer se reinicia automáticamente y se inicia un nuevo ciclo de acumulación. El badge cambia a "Promedio de 5 horas completado" mientras el contador de muestras se reinicia a 0.

Obtención de API Key para Google AI Studio

  1. Acceda a Google AI Studio con una cuenta de Google.
  2. Cree un proyecto o seleccione uno existente.
  3. Genere una clave de API en la sección de configuración del proyecto.
  4. Haga clic en el botón "API Key" de esta interfaz e ingrese la clave cuando se le solicite.
  5. La clave se guarda en localStorage del navegador y se utiliza en la cabecera x-goog-api-key para todas las llamadas a la API de Gemini.
